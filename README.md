# TypeScript Journey 🚀

Repositorio personal de prácticas y ejercicios enfocados en el aprendizaje de **TypeScript**, con el objetivo de fortalecer los fundamentos de programación que serán aplicados posteriormente en proyectos de **QA Automation**.

## 📚 Objetivos

- Dominar la sintaxis de TypeScript.
- Comprender el sistema de tipos.
- Aplicar conceptos de Programación Orientada a Objetos (POO).
- Utilizar interfaces, clases, herencia y modificadores de acceso.
- Trabajar con funciones, arrays, objetos y genéricos.
- Construir una base sólida para frameworks de automatización como:
  - Playwright
  - Selenium
  - Cypress
  - WebdriverIO

## 🛠️ Temas Prácticados

- Variables y tipos de datos
- Type Aliases
- Interfaces
- Enums
- Funciones
- Arrays y Objetos
- Union Types
- Type Guards
- Null y Undefined
- Strict Null Checks
- Programación Orientada a Objetos
- Clases e Instancias
- Herencia
- Encapsulamiento
- Modificadores de acceso (`public`, `private`, `protected`)
- Readonly
- Manejo de errores
